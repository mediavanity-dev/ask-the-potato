# 🥔 Ask the Potato

A wise potato oracle that answers your yes/no questions.

**Try it:** https://mediavanity-dev.github.io/ask-the-potato/

Type a question, hit **Ask!**, and the ancient spud will consult the root vegetables. Poke the potato at your own risk.

The whole app is a single [index.html](index.html), with no build step and no dependencies.
